# dev-standards

repository for scripts and standards for building a project & repo scaffolding

---

## Quick Start

```sh
git clone https://github.com/pdrangeid/dev-standards.git
cd dev-standards
source activate_env.sh
uv pip install -e .[dev]
cp .env.example .env  # fill in credentials
```
